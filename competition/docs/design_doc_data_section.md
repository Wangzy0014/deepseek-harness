# 设计方案文档 · 数据处理与学情统计章节（草稿，负责人：魏文宇）

> 本文件是最终提交 PDF（≤20 页）中数据章节的草稿。遵守仓库数据安全规则：
> 公开仓库版本不含任何记录级真实编号与作答内容；定稿时在离线稿中补入
> 具体记录编号作为证据（本机 `outputs/` 已备好对应材料）。

## 1. 数据说明与字段映射

系统输入为赛题提供的六张表（课程要求、题目与材料、模拟学生、测验节点、
作答记录、字段说明）。加载层将中文列名一一映射为程序字段
（`field_mapping.csv`），并做三类结构校验：必备列齐全、主键唯一、
引用完整（记录 → 学生/材料/节点均可解析）；违反字段契约的行在加载层
即拒绝并给出可定位的错误信息，保证后续统计不出现口径分叉。

## 2. 统一清洗入口（全队唯一）

所有下游模块（比较、诊断、建议）一律通过 `study_companion.clean.
build_valid_records` 获取"当前有效记录"，禁止各自清洗。清洗包含两步：

### 2.1 版本归并

同一作答事件（学生-节点-材料）存在多个修订版本时，只保留最高修订
版本进入当前记录；被归并旧版本完整保留于 `history` 字段，可查可审计。
公开数据实测：806 行 → 799 个事件，7 个多版本事件不重复计数。

### 2.2 异常识别与处置（依据可追溯）

对归并后的当前记录识别六类已知冲突，处置与依据写入质量报告：

| 异常类型 | 识别规则 | 处置 | 依据 |
| --- | --- | --- | --- |
| 主题不一致 | 记录主题 ≠ 题库主题 | 以题库为准修正，保留原文 | 题库为权威映射 |
| 得分超满分 | 得分 > 满分 | 隔离（不进统计） | 验收书：不能直接进入统计 |
| 总分与评分点矛盾 | 评分点合计 ≠ 总分 | 隔离（不进统计） | 无法仲裁真值 |
| 节点范围外 | 材料不在该节点可用题集 | 保留原节点不迁移，隔离 | 不能仅按时间戳改节点 |
| 答案与参考一致却 0 分 | 归一化后逐字符相等 | 保留原分，标记人工复核 | 进入语义评分复核 |
| 满分与题库不一致 | 记录满分 ≠ 题库满分 | 以题库为准修正 | 题库为权威来源 |

公开数据实测：六类冲突各至少 1 条、共 6 条记录命中，全部带处置与依据。
得分矛盾的处置另提供"评分点自洽修正"备选策略（评分点合计==满分时按
评分点修正），默认关闭，切换由团队统一决策（备忘录见本机 outputs/）。

## 3. 统计口径

- **分母**：得分率分母 = 计入统计的已评分记录满分之和（非可用题数）；
- **状态区别**：已评分（计入/隔离）、待评分、未作答、无记录分别计数，
  互不折算——零分（真 0）与"本节点未教学"严格区分，后者显示为
  "未教学（本节点未测量）"而非 0%；
- **记录不足**：学生×节点无任何记录时输出明确的"记录不足"提示，
  不推断为未掌握或全部掌握；
- **节点隔离**：两个测验节点的统计互不混比；
- **同伴比较**：班级汇总支持排除本人，"排除后参考值"真实生效。

## 4. 结果验证

- **独立复算**：与独立实现的参考口径（含按验收书条文独立编写的
  预言机）对全部学生×节点对账，数值完全一致；
- **性质测试**：200 套随机数据集（随机注入六类异常、修订链、无记录）
  与独立预言机逐记录等价对拍，并校验核心不变量：归并无损
  （当前+历史=原始全量）、全局总量守恒、隔离记录无有效得分、
  覆盖自洽、处置幂等；
- **产物一致性**：JSON 与 CSV 产物由同一次计算产生，合计值三方一致；
- **可复现**：管线幂等，重复运行产物逐字节一致；换目录重跑结果不变。

## 5. 输出与接口（下游模块使用方式）

当前有效记录（JSON/CSV）、质量报告、学生×节点统计、覆盖表、证据查询
（学生/题目/记录/指标，含全部历史版本）、步骤诊断线索（末步结论与最终
作答的矛盾筛查，供诊断模块定位，不参与统计口径）。命令行入口：`check /
stats / class / evidence / pipeline / mapping`，Python 入口见
`competition/README.md`（顶层包已导出常用函数）。
