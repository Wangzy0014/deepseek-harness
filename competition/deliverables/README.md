# 最终成果包结构（骨架，魏文宇兼任维护）

按参赛说明：任务成果包须含学习内容梳理、个体与群体学情分析、个性化
学习建议等成果，结构化结果采用 JSON、CSV 等可机读格式，附字段说明、
输入输出样例和必要操作说明。四人把各自产物按下述结构归位，最终由
魏文宇统一合并（不代写他人模块）。

```
成果包/
  README.md                     操作说明：如何重跑全链路、如何核对关键数字
  01_学习内容梳理/               ← 纪宏锋（课程要求清单、主题-课标-教材-题目索引）
  02_学情分析/
    数据处理/                   ← 魏文宇（valid_records、quality_report、
    │                            field_mapping、复算说明）
    个人与班级统计/             ← 魏文宇（student_stats、coverage、班级汇总）
    同题比较与班级对照/         ← 宗博文（比较入口、两班对照、样本与权重说明）
    学习诊断/                   ← 纪宏锋（步骤诊断、依据与不确定事项）
  03_学习建议/                  ← 王振宇（学习计划、分层提示、补充练习、调整条件）
  04_字段说明/                  各 JSON/CSV 的字段字典（复用 shared/contracts 契约）
  05_输入输出样例/              三名代表学生案例的完整证据链
  06_分析脚本/                  可选提交；含"干净目录重跑"说明
```

归位规则：

1. **文件名不带空格**，用下划线；每个机读文件同名附带 `.字段说明.md`
   或在 04_ 统一登记；
2. 每个模块的产物必须能由"干净输出目录重跑"复现（验收项），提交前
   在本机 `outputs/` 先重跑一遍核对；
3. 真实数据衍生文件**不进仓库**（公开仓库），成果包在队内渠道汇总；
4. 三名代表学生案例（部分得分/表现较好/记录不足）的候选与依据见
   本机 `outputs/samples/showcase_candidates.json` 与处置备忘录
   （真实编号不入库，队内渠道传阅）。
