# 学习要求索引与作答诊断

本模块提供 `get_curriculum(dataset, { topic_id? })` 和 `diagnose_student(dataset, { student_id, node_id })`，返回统一 `team-v1` 结果。统计事实沿用数据模块的最高修订、质量隔离和节点范围；未知编号返回错误。

课程索引从输入课程要求、题目和材料表建立主题、指标、题目、学习卡与教材关系。课标文件页、正文页和教材正文页保留输入定位；未提供或格式不明时为 `null`。接口以 `input_index` 表明页码来自输入索引，不能把页码存在解释为本函数已核验 PDF。教材关系采用主题及材料标题匹配；未找到的材料不会补造编号。式的学习与方程、不等式之间的支持关系标为教学组织建议。

诊断结果分别标识事实、推断、证据不足和评分待复核。当前规则能从相邻的简单一元不等式变形中确认除以负数后未改变方向，返回原记录、实际步骤编号、相关评分点和学习材料。它只在变量和除法后的数值均可直接核对时定位此问题，连带错误的后续解集不重复计为第二个漏洞。其他失分仅报告评分与记录观察，不编造过程或心理原因。没有过程时步骤引用为空。

原始质量问题记录只产生评分复核项；如果明确步骤错误却获得相关分点分数，也产生评分复核项。该情况下保留原统计以便核对，并要求教师先确认过程和评分，不能直接用复核项推断薄弱能力。满分观察仅适用于当前已覆盖题目和指标。补充观察只针对当前节点可测而缺少有效记录的指标；未教学主题不会列作薄弱内容。

测试使用独立合成数据。设置 `STUDY_DATA_DIR` 后才核验本地赛题输入中的三主题九指标、代表学生、最新修订和材料引用；原始资料与诊断导出不纳入 Git。自动核验不能替代队员真人复验。
